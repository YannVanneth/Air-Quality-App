# Air Quality Monitoring Project ✈️

## Overview 🚃
This project is a student assignment for the Royal University of Phnom Penh (RUPP) under the Department of Computer Science. It focuses on monitoring air quality using affordable tools, providing real-time data on pollutants like PM2.5 and AQI. The aim is to demonstrate practical application of programming and hardware skills while addressing environmental issues in Cambodia.
